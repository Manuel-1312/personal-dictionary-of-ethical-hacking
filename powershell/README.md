# 💻 PowerShell Tools

🪟 Esta carpeta reúne utilidades PowerShell pensadas para Windows, inventario, reporting,
red local y alguna que otra pieza visual para que no todo sea gris administrativo.

> [!NOTE]
> Todos los scripts están diseñados para funcionar con cero o muy pocas dependencias extra
> y producir salidas fáciles de guardar en CSV, JSON o Markdown.

---

## 📂 Subcategorías

- **⚙️ `system/`** → procesos, servicios, tareas, arranque y estado general del sistema.
- **📁 `files/`** → inventario de carpetas, archivos grandes, extensiones y orden ligero.
- **🌐 `network/`** → instantáneas de red local, conexiones y comprobaciones básicas.
- **📊 `reporting/`** → conversión de datos a formatos más legibles y plantillas rápidas.
- **🎉 `fun/`** → pequeños scripts visuales o simpáticos para consola y demos.
- **📋 `DEPENDENCIES.md`** → mapa rápido de requisitos, cmdlets y utilidades del sistema por categoría.

---

## 🧭 Filosofía

- Scripts sencillos
- Cero o muy pocas dependencias extra
- Útiles de verdad en Windows
- Con outputs fáciles de guardar en CSV, JSON o Markdown
